# A14 — AI-enabled Security Solutions

# Objective
Investigate and describe 5 AI-enabled cybersecurity solutions, understanding how AI enhances security effectiveness.

# Tool 1: Darktrace
**Type:** AI-based threat detection  
**Description:** Uses machine learning to detect unusual network behaviour and potential cyber threats automatically.  
**Security Purpose:** Detects zero-day attacks and insider threats in real time.  

# Tool 2: CrowdStrike Falcon
**Type:** AI-powered endpoint protection  
**Description:** Detects and prevents malware and ransomware using AI analytics.  
**Security Purpose:** Cloud-native solution for real-time endpoint security.

# Tool 3: Microsoft Defender with AI
**Type:** AI-enabled antivirus / endpoint protection  
**Description:** Uses AI models to identify malware patterns and suspicious activity.  
**Security Purpose:** Protects endpoints from emerging threats using predictive AI.

# Tool 4: CylancePROTECT
**Type:** AI-based malware prevention  
**Description:** Predicts and prevents malware execution before it runs using machine learning.  
**Security Purpose:** Stops malware pre-execution, reducing risk of infection.

# Tool 5: Vectra AI
**Type:** AI-driven network threat detection  
**Description:** Monitors network traffic for unusual patterns to detect cyberattacks in real time.  
**Security Purpose:** Enhances situational awareness and rapid response to network threats.

# Reflection
Through this activity, I learned that AI is becoming a critical part of modern cybersecurity, enabling proactive detection and prevention of threats across endpoints and networks. Integrating AI solutions helps organizations stay ahead of sophisticated attacks while reducing human monitoring overhead.

# B18 — Contribute to an Open-Source Project Related to Cybersecurity

## Objective
The purpose of this activity is to contribute to an open-source cybersecurity-related project.

---

## Description
An open-source cybersecurity project was reviewed on GitHub, and a contribution/suggestion was prepared to improve cybersecurity awareness and secure practices.

The contribution focused on improving password security recommendations and cybersecurity documentation.

---

## Contribution Details

### Project Reviewed
OWASP Juice Shop (Open-source cybersecurity project)

### Contribution Type
Documentation/security improvement suggestion.

### Suggested Improvement
Recommended stronger password security practices such as:
- enabling MFA,
- using password managers,
- and avoiding password reuse.

---

## Outcome
This activity demonstrated participation in the open-source cybersecurity community and awareness of secure development practices.

---

## Conclusion
Contributing to open-source cybersecurity projects helps improve community-driven security awareness and promotes collaborative cybersecurity improvements.

# B20 — Enhance the Security of a GitHub Project

## Objective
The purpose of this activity is to improve the security of a GitHub project by applying secure repository management practices.

---

## Description
Security improvements were applied to the GitHub portfolio repository.

The improvements included:
- creating a `.gitignore` file,
- excluding sensitive/unnecessary files,
- improving repository organization,
- and documenting security practices in the README file.

---

## Security Enhancements Applied

### 1. `.gitignore` Configuration

#### Purpose
Prevent unnecessary or sensitive files from being uploaded to GitHub.

#### Benefit
Reduces accidental exposure of sensitive information.

---

### 2. Security Documentation in README

#### Purpose
Document repository security practices and secure development considerations.

#### Benefit
Improves repository transparency and security awareness.

---

## Outcome
This activity demonstrated how GitHub repositories can be improved using secure development and repository management practices.

---

## Conclusion
Applying security practices such as `.gitignore` configuration and secure documentation helps improve GitHub project security and reduces accidental data exposure risks.

# B17 — Implement and Evaluate a State-of-the-Art Cybersecurity Solution

## Objective
The purpose of this activity is to implement and evaluate a modern state-of-the-art cybersecurity solution.

---

## Description
Multi-Factor Authentication (MFA) was implemented and evaluated as a modern cybersecurity solution for account protection.

MFA adds an additional authentication step beyond passwords to improve account security.

---

## Implementation

### Solution Implemented
Multi-Factor Authentication (MFA)

### Application
MFA was enabled on an online account and tested during the login process.

### Security Benefit
MFA significantly reduces the risk of unauthorized access and account compromise.

---

## Evaluation

### Advantages
- Improved account protection
- Additional authentication security layer
- Reduced password-only attack risks

### Limitations
- Slightly longer login process
- Dependence on secondary verification device

### Overall Evaluation
MFA is highly effective and widely used as a modern cybersecurity protection mechanism.

---

## Outcome
This activity demonstrated the implementation and practical evaluation of a modern cybersecurity solution.

---

## Conclusion
Modern cybersecurity solutions such as MFA provide strong protection against account compromise and improve overall digital security.

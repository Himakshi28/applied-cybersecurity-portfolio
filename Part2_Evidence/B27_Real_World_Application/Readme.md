# B27 — Apply a Learned Cybersecurity Concept to a Real-World Application

## Objective
The purpose of this activity is to apply a cybersecurity concept learned during the unit to a real-world scenario.

---

## Description
A file encryption concept learned during the unit was applied to protect sensitive information stored locally on a device.

A text file containing simulated sensitive information was created and encrypted using a Python-based file encryption tool developed during previous activities.

---

## Real-World Scenario

### Original File
A file containing simulated personal and sensitive information was created.

### Cybersecurity Concept Applied
File encryption was applied to protect the confidentiality of the data.

### Security Benefit
Encryption prevents unauthorized users from reading sensitive information if the file is accessed without permission.

---

---

## Outcome
This activity demonstrated how encryption can be used in real-world environments to protect sensitive data and improve privacy.

---

## Conclusion
Applying encryption in practical scenarios helps protect confidential information and demonstrates the importance of cybersecurity techniques in everyday digital environments.

# B22 — Enhance the Cybersecurity of a Website from Your Community

## Objective
The purpose of this activity is to improve the cybersecurity of a website by implementing stronger authentication and secure design practices.

---

## Description
A community-style login webpage was created and then enhanced with additional cybersecurity protections and secure authentication improvements.

The activity demonstrated how website security can be improved using modern cybersecurity concepts.

---

## Initial Website Security Issues

The original login page lacked:
- strong password recommendations,
- multi-factor authentication (MFA),
- required field validation,
- and secure login guidance.

## Security Enhancements Implemented

The following security improvements were added:
- stronger password recommendations,
- required login validation,
- MFA support option,
- and HTTPS security awareness.


## Comparison
A comparison between the insecure and secure versions demonstrated the cybersecurity enhancements applied.


## Outcome
This activity demonstrated how secure authentication and cybersecurity awareness features can improve website security.

---

## Conclusion
Implementing secure authentication practices and cybersecurity protections helps reduce website security risks and improves user safety.

# B21 — Design and Implement a Cybersecurity Learning Activity

## Objective
The purpose of this activity is to design and implement a cybersecurity learning activity to improve cybersecurity awareness and education.

---

## Description
A phishing awareness quiz was designed and implemented as a cybersecurity learning activity.

The activity included:
- multiple-choice questions,
- phishing identification concepts,
- cybersecurity awareness content,
- and practical security advice.

The goal was to help users recognize phishing attacks and improve online safety awareness.

---

## Learning Objectives
Participants should be able to:
- understand phishing attacks,
- identify suspicious emails and links,
- recognize phishing warning signs,
- and apply safer online practices.

---

## Outcome
This activity demonstrated how cybersecurity education activities can improve awareness and encourage safer online behavior.

---

## Conclusion
Cybersecurity learning activities are important tools for improving awareness and helping users recognize common cyber threats such as phishing attacks.

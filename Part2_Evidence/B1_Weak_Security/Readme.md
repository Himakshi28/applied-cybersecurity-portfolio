# B1 — Discover 5 Unique Weak/Vulnerable Security Implementations

## Objective
The purpose of this activity is to identify weak or vulnerable security implementations that may increase cybersecurity risks.

---

## Weak Security Implementation 1 — Weak Password

### Observation
A weak password example was identified using a simple and predictable password.

### Security Risk
Weak passwords are easily guessed or brute-forced by attackers.

---

## Weak Security Implementation 2 — Password Written on Sticky Note

### Observation
A password written on a sticky note was observed.

### Security Risk
Anyone with physical access can view and misuse the password.

---

## Weak Security Implementation 3 — Unlocked Computer

### Observation
A computer/laptop was left unlocked in a public/shared environment.

### Security Risk
Unauthorized users could access files, accounts, or sensitive data.

---

## Weak Security Implementation 4 — Unsecured Public Wi-Fi

### Observation
An open/public Wi-Fi network without password protection was identified.

### Security Risk
Attackers may intercept traffic or perform network-based attacks.

---

## Weak Security Implementation 5 — Password Reuse

### Observation
The same password was reused across multiple accounts.

### Security Risk
If one account is compromised, attackers may access additional accounts.


---

## Outcome
This activity demonstrated how weak security practices can significantly increase cybersecurity risks.

---

## Conclusion
Identifying vulnerable security implementations helps improve security awareness and encourages stronger cybersecurity practices.

# B3 — Discover 3 Proactive Security Implementations in Practice

## Objective
The purpose of this activity is to identify proactive security implementations that help prevent cybersecurity threats before incidents occur.

---

## Proactive Security Implementation 1 — FileVault Encryption

### Observation
FileVault full-disk encryption was enabled on the macOS device.

### Proactive Security Benefit
FileVault proactively protects sensitive data by encrypting files and preventing unauthorized access if the device is lost or stolen.

---

## Proactive Security Implementation 2 — Automatic Software Updates

### Observation
Automatic updates were enabled on the system.

### Proactive Security Benefit
Automatic updates proactively patch software vulnerabilities before attackers can exploit them.


---

## Proactive Security Implementation 3 — Firewall Protection

### Observation
The system firewall was enabled.

### Proactive Security Benefit
Firewalls proactively monitor and restrict unauthorized incoming network connections.

---

## Outcome
This activity demonstrated how proactive cybersecurity measures help reduce risks before security incidents occur.

---

## Conclusion
Proactive security implementations such as encryption, software updates, and firewalls are essential for preventing cyber attacks and improving overall system security.

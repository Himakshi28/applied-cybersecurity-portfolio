# B24 — Design and Implement Access Control

## Objective
The purpose of this activity is to design and implement an access control mechanism to protect sensitive information.

---

## Description
An access control mechanism was implemented using password-protected notes on a macOS device.

A sensitive note was created and secured using a password lock to restrict unauthorized access.

---

## Access Control Design

### Protected Resource
A private note containing sensitive information.

### Access Control Mechanism
Password-based authentication using the built-in note locking feature.

### Security Benefit
Only authorized users with the correct password can access the protected information.

---

## Outcome
This activity demonstrated how access control mechanisms can protect sensitive information from unauthorized access.

---

## Conclusion
Access control is an essential cybersecurity principle used to restrict access to sensitive resources and improve data security.

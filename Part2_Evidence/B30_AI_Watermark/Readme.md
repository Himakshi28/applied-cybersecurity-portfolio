# B30 — AI-Created Image Watermark Survival Test

## Objective
The purpose of this activity is to test whether a watermark applied to an AI-generated image remains detectable after image editing or regeneration.

---

## Description
An AI-generated cybersecurity-themed image was created and digitally watermarked. The image was then edited to verify whether the watermark remained visible after modification.

---

## Process

### 1. AI Image Generation
An AI-generated cybersecurity image was created using an online AI image generation tool.

### 2. Watermark Application
A visible watermark was added to the image.

### 3. Image Modification
The image was edited using basic transformations such as cropping and visual adjustments.

### 4. Watermark Verification
The watermark remained visible after the editing process.

---

## Outcome
This activity demonstrated how digital watermarking techniques can help preserve ownership and authenticity of AI-generated media.

---

## Conclusion
Watermarking is an important technique for identifying AI-generated content and improving digital media authenticity and traceability.

# A10 — Discover Privacy Techniques Used Offline

# Objective
Identify and document privacy techniques that protect personal information locally on devices, without relying on internet connectivity.

# Privacy Techniques Identified

# 1. Locked Notes
**Function:** Notes or documents locked with a password.  
**Privacy Benefit:** Keeps sensitive data private offline.

# 2. Auto-Lock / Screen Lock
**Function:** Device locks automatically after inactivity.  
**Privacy Benefit:** Prevents unauthorized access when device is unattended.

# 3. Local VPN / Private Network Config
**Function:** VPN or local network privacy settings.  
**Privacy Benefit:** Keeps network traffic private offline.

# 4. Encrypted External Drive / USB
**Function:** Encrypt removable storage using APFS/FileVault.  
**Privacy Benefit:** Protects data from unauthorized access if the device is lost.

# 5. Keychain Access
**Function:** Encrypted storage of passwords and credentials.  
**Privacy Benefit:** Safely stores credentials locally without network exposure.

# Outcome
These offline privacy techniques help protect personal information, credentials, and sensitive files without requiring internet connectivity.

# Conclusion
Offline privacy mechanisms provide critical layers of protection on personal devices, complementing online security measures and maintaining confidentiality in everyday use.

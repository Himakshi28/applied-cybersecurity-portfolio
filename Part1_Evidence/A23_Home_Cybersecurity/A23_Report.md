# A23 — Enhancing Cybersecurity at Home

# Objective
To enhance the cybersecurity of my home environment by implementing practical measures that protect devices, accounts, and networks from common threats.

# Enhancement 1: Enable Multi-Factor Authentication (MFA)
**Description:** Added MFA to my email and key online accounts.  
**Security Purpose:** Adds a second layer of security, reducing risk of account compromise even if passwords are stolen.

# Enhancement 2: Enable Automatic Updates
**Description:** Turned on automatic updates for all devices, including PC and smartphone.  
**Security Purpose:** Ensures security patches are applied promptly, protecting against known vulnerabilities.

# Enhancement 3: Install / Verify Antivirus Protection
**Description:** Installed/verified antivirus software on devices.  
**Security Purpose:** Protects against malware, ransomware, and other cyber threats.

# Enhancement 4: Change Default Passwords
**Description:** Changed default passwords on Wi-Fi and IoT devices to strong, unique passwords.  
**Security Purpose:** Prevents attackers from exploiting default credentials to access devices or network.

# Reflection
Through this activity, I learned that **cybersecurity isn’t just about software** — physical devices, account settings, and network configurations are equally important. Implementing these changes improved my **overall security posture** at home, reducing potential vulnerabilities and making my environment more resilient to attacks.

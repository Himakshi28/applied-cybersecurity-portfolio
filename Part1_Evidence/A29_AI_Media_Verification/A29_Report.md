# A29 — AI Generated Media Verification

# Objective
The goal of this activity is to identify and verify whether a publicly available image was generated using Artificial Intelligence by using an AI detection and verification tool.

# Step 1: Finding AI-Generated Media
An AI-generated human face image was obtained from the website:

https://thispersondoesnotexist.com

This website generates synthetic human faces using Generative Adversarial Networks (GANs). The individuals shown do not exist in reality.

Evidence:
- Screenshot showing the generated image and website source.

# Step 2: Verification Using Detection Tool
The image was analysed using an AI content detection tool (Hive AI Detection).

The tool analysed the image and provided a probability score indicating whether the image was AI-generated.

Evidence:
- Screenshot showing uploaded image and detection results.

# Analysis
The detection results indicated a high likelihood that the image was artificially generated. This demonstrates how verification tools can help identify synthetic media and reduce risks related to misinformation, impersonation, and deepfakes.

# Security Relevance
AI-generated media presents cybersecurity risks such as:
- Deepfake identity fraud
- Social engineering attacks
- Disinformation campaigns

Detection tools play an important role in modern cybersecurity by helping users validate digital content authenticity.


# Conclusion
This activity demonstrated practical verification of AI-generated media using real-world tools. The experiment highlights the importance of combining human awareness with automated detection systems to identify synthetic digital content.

# A13 — Discover 5 Unique Online Security Tools

# Objective
The purpose of this activity was to investigate commonly used online cybersecurity tools that assist users in analysing threats, verifying system security, and improving online safety practices

# Tool 1: VirusTotal
**Website:** https://www.virustotal.com

**Description:**  
VirusTotal is an online cybersecurity service owned by Google that analyses files, URLs, and hashes using multiple antivirus engines and threat intelligence databases simultaneously.

**Security Purpose:**  
It helps users identify malware before downloading or executing suspicious files or visiting unknown websites.

**Evidence:**  
Screenshot shows scan results generated before and after analysing a sample file.

**Reflection:**  
This tool demonstrates how collaborative intelligence from multiple vendors improves malware detection reliability.

# Tool 2: Have I Been Pwned
**Website:** https://haveibeenpwned.com

**Description:**  
Have I Been Pwned is a breach notification platform created by security researcher Troy Hunt that allows users to check whether their email addresses or passwords have been exposed in known data breaches.

**Security Purpose:**  
Encourages stronger password practices and awareness of credential compromise.

**Evidence:**  
Screenshot shows breach lookup results for an email search.

**Reflection:**  
This highlights how data breaches are widespread and why password reuse creates major security risks.

## Tool 3: SSL Labs Server Test
**Website:** https://www.ssllabs.com/ssltest/

**Description:**  
SSL Labs Server Test is an online diagnostic tool that evaluates the SSL/TLS configuration of web servers, including encryption strength, certificate validity, and protocol support.

**Security Purpose:**  
Helps administrators and users verify whether websites implement secure HTTPS communication properly.

**Evidence:**  
Screenshot displays the security grading report of a tested website.

**Reflection:**  
I learned that HTTPS security depends not only on encryption but also correct configuration and protocol selectio

# Tool 4: SecurityHeaders
**Website:** https://securityheaders.com

**Description:**  
SecurityHeaders analyses HTTP response headers implemented by websites and evaluates protection mechanisms against common web attacks such as cross-site scripting (XSS), clickjacking, and MIME-type attacks.

**Security Purpose:**  
Identifies missing browser security protections and suggests improvements.

**Evidence:**  
Screenshot shows header evaluation results and assigned security rating.

**Reflection:**  
This tool shows how small backend configurations significantly improve web application security.

## Tool 5: DNS Checker
**Website:** https://dnschecker.org

**Description:**  
DNS Checker is an online network diagnostic tool that verifies DNS record propagation across global servers and provides insight into domain resolution behaviour.

**Security Purpose:**  
Helps analyse domain infrastructure visibility and detect DNS misconfigurations that may affect availability or security.

**Evidence:**  
Screenshot shows DNS lookup results across multiple geographic locations.

**Reflection:**  
This activity demonstrated that DNS infrastructure plays a critical role in secure and reliable internet communication

# Overall Learning Reflection
Through this activity, I learned that cybersecurity defence relies heavily on accessible online analysis tools. These platforms allow both professionals and everyday users to detect threats, verify configurations, and better understand security risks without requiring advanced technical expertise.

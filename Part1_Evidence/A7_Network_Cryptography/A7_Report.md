# A7 — Cryptography in Modern Networks

# Objective
To identify and document cryptography used in modern networks, demonstrating how data is protected during transmission.

# Observation
I examined my home Wi-Fi network and found it uses **WPA2/WPA3 Personal encryption**. The screenshot shows the network name and the security type.

## Security Purpose
Wi-Fi encryption ensures:
- **Confidentiality** — prevents unauthorized users from reading network traffic.
- **Integrity** — ensures transmitted data is not tampered with.
- **Authentication** — only authorized devices can connect to the network.

By using WPA2/WPA3, network communications are **encrypted**, reducing the risk of eavesdropping or interception.

# Reflection
This activity highlighted the importance of network-level cryptography in everyday devices. Even basic configurations like WPA3 improve security significantly, showing how modern networks use cryptography to protect users’ data.

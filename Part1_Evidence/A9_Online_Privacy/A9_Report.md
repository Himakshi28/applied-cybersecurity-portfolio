# A9 — Online Privacy Technique

# Objective
To identify and document a privacy technique used online, demonstrating how services protect user data.

# Observation
I used **Google Chrome’s Incognito Mode**. The URL bar displays the **Incognito icon (hat & glasses)** and a message stating that browsing history, cookies, and site data will not be saved during this session.  

**Evidence:** 1_IncognitoChrome.png

# Security Purpose
Incognito mode protects user privacy by:  
- **Not storing browsing history** on the local device.  
- **Clearing cookies and site data** after the session ends.  
- **Preventing autofill of form data** and temporary cache storage.  

While it does not make the user completely anonymous online, it **reduces the footprint of personal activity on the device**, making it useful for sensitive browsing or shared devices.

# Reflection
This activity highlighted a simple yet effective **online privacy feature** that is widely available to users. It reinforced the importance of understanding and using privacy tools to control personal data exposure. Even basic techniques like Incognito mode contribute to a stronger overall cybersecurity posture.

# A12 — Discover 5 Unique Offline Security Tools

# Objective
The purpose of this activity is to identify and document offline security tools that protect people, assets, and infrastructure without relying on internet connectivity.

# Description
Five physical security mechanisms observed in a real-world environment were recorded. These tools provide protection through access control, monitoring, and emergency response.

# Security Tools Identified

# 1. Eaton Call Point with LED & Backoff
**Function:** Emergency alarm activated manually in case of fire or hazard.  
**Security Benefit:** Alerts occupants immediately, enabling quick evacuation and emergency response.

# 2. Card Tap Entry Lock
**Function:** Access control using authorized cards to unlock doors.  
**Security Benefit:** Restricts access to authorized personnel only, preventing unauthorized entry.

# 3. Key Lock Entry
**Function:** Mechanical lock securing doors or cabinets.  
**Security Benefit:** Provides physical access restriction and prevents unauthorized entry.

# 4. Fire Extinguisher
**Function:** Used to control small fires during emergencies.  
**Security Benefit:** Reduces risk of injury and property damage in fire incidents.

# 5. CCTV Camera
**Function:** Monitors activities in public or restricted areas.  
**Security Benefit:** Acts as a deterrent, records evidence, and helps in incident investigation.

# Outcome
This activity demonstrated that offline security tools are essential components of a layered security strategy. Physical tools complement digital security measures and help protect people, property, and sensitive areas.

# Conclusion
Offline security mechanisms such as alarms, locks, and monitoring devices play a critical role in maintaining safety and security, even without internet or network connectivity.

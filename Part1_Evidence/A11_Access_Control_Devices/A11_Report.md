# A11 — 5 Unique Access Control Devices

# Objective
The goal of this activity is to identify and provide evidence of 5 unique access control devices used in modern security systems.

# Devices Collected

# 1. Keyless Entry Lock
- A keyless door lock allows access without physical keys, often using a code or mobile app.
- Enhances security by eliminating the risk of lost or duplicated keys.
- Evidence: Screenshot of product page / security description.

# 2. RFID Facial Recognition
- Combines RFID card access with facial recognition for multi-layer security.
- Ensures only authorized personnel gain access by verifying both card and identity.
- Evidence: Screenshot of product webpage / description.

# 3. Smart Door with Password
- Smart doors that use numeric or alphanumeric passwords for entry.
- Convenient and secure for homes and offices; passwords can be updated remotely.
- Evidence: Screenshot showing device and security explanation.

# 4. Touch ID (Biometric Fingerprint Scanner)
- Uses fingerprint recognition to authenticate users.
- Prevents unauthorized access and ensures identity-based security.
- Evidence: Screenshot from official Apple Touch ID support page.

# 5. Two-Factor Authentication (2FA / OTP)
- Adds an extra layer of security by requiring a one-time password along with a login.
- Protects online accounts and systems against password theft.
- Evidence: Screenshot from Google Authenticator / official 2FA documentation.

# Security Relevance
Access control devices are crucial in cybersecurity and physical security, as they:

- Prevent unauthorized access  
- Reduce risk of theft or tampering  
- Enable audit trails of user access  
- Provide multi-factor security layers

# Conclusion
This activity demonstrates practical understanding and research on modern access control technologies, showing how multiple devices enhance security in both physical and digital environments.
